
Other Great Short-and-Punchy Vibecode ExperimentsIf you want to try a few different 100-line experiments with VS Code agents, here are three high-yield ideas:1. An ASCII Graph / Chart Generator for Terminal:The Prompt: "Write a CLI tool that takes an array of numbers and renders a clean ASCII bar chart or sparkline graph directly in the terminal."Why it's fun to roast: Agents always get padding, alignment, and maximum height calculations wrong on the first pass.2. A Terminal Byte-Viewer / Hex Dump Tool (xxd clone):The Prompt: "Build a CLI utility that takes a file and prints its hex addresses, raw hex bytes, and ASCII representation side-by-side with ANSI colors."Why it's fun to roast: They almost always mess up line wrapping on the last remaining bytes of a file.3. A Custom String Diff / Text Comparison Engine:The Prompt: "Write a script that compares two strings and outputs side-by-side green/red terminal highlights for added/removed words without using external libraries."Why it's fun to roast: Longest Common Subsequence (LCS) algorithms are easy to over-engineer or turn into $O(N^2)$ memory hogs.
