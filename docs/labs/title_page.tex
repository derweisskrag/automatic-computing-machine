\begin{abstract}
This homework focuses on the implementation of a concurrent priority queue 
to serve as a task scheduler. The main objective is to design and implement 
a system that can manage and execute tasks based on their priority levels 
while ensuring thread safety and efficient concurrency. The implementation 
will be done in both Python and Rust, allowing for a comparison of performance 
and ease of use between the two languages. The task scheduler will be tested 
with various workloads to evaluate its effectiveness in handling concurrent 
tasks with different priorities.
\end{abstract}
